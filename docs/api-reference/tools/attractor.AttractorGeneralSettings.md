# csc.tools.attractor.AttractorGeneralSettings

> 公式: https://cascadeur.com/python-api/_generate/csc.tools.attractor.AttractorGeneralSettings.html

Settings configuration for the attractor tool in Cascadeur.

## Properties

- **factor**: Adjustment multiplier for attractor influence
- **mode**: Specifies the attractor operational mode
- **mode_relative_to_pivot**: Boolean indicating if mode is relative to pivot point
- **physic_type**: Defines the physics type applied by the attractor
- **pivot**: Reference point for attractor calculations
- **position_axis**: Axis constraints for position attraction
- **rotation_axis**: Axis constraints for rotation attraction
- **scale_axis**: Axis constraints for scale attraction

- **`__init__(self: csc.tools.attractor.AttractorGeneralSettings) → None`**: Initializes a new AttractorGeneralSettings instance
