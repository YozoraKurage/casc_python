# csc.tools.JointData

> 公式: https://cascadeur.com/python-api/_generate/csc.tools.JointData.html

Represents joint data used in Cascadeur to manage local position, rotation, and scale of joints.

## Properties

- **local_position**: Local position (numpy.ndarray)
- **local_rotation**: Local rotation (csc.math.Rotation)
- **local_scale**: Local scale (numpy.ndarray)
- **visibility**: Visibility (int)
