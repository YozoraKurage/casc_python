# csc.parts.SceneClipboard

> 公式: https://cascadeur.com/python-api/_generate/csc.parts.SceneClipboard.html

Provides methods to operate parts of the scene.

## Methods

- `__init__(self, *args, **kwargs)` - Constructor

- `copy(self: csc.parts.SceneClipboard, arg0: csc.view.Scene) → None` - Copy scene content to clipboard

- `copy_image_to_clipboard(self: csc.parts.SceneClipboard, arg0: csc.view.Scene) → None` - Copy scene image to clipboard

- `paste(self: csc.parts.SceneClipboard, arg0: csc.view.Scene) → None` - Paste clipboard content into scene

- `paste_with_session(self: csc.parts.SceneClipboard, arg0: csc.view.Scene, arg1: csc.domain.Session) → None` - Paste clipboard content into scene with session context
